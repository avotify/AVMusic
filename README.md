# AVMusic
Create a full-scale music streaming platform called “AV Music” similar to Spotify, available on Web, Android, and iOS.

BRAND:
Name: AV Music
Logo: “AV” in a futuristic, premium style
Colors:
- Black #000000
- Neon Blue #0A84FF
- Dark Blue #081A2F
Style: luxury, modern, tech, minimal, cinematic

CORE FEATURES:
Users can:
- Create account (email, Google, Apple)
- Login securely
- Browse music by:
  - Genres
  - Artists
  - Albums
  - Mood
- Search any song, artist, or playlist
- Stream music instantly
- Create, edit, and share playlists
- Like songs
- Download songs for offline (premium)
- See lyrics in real-time
- Get AI-powered recommendations
- See “Trending”, “New Releases”, “For You”
- View listening history

PLAYER:
Bottom floating player with:
- Album art
- Song name + artist
- Play/Pause
- Next / Previous
- Repeat, Shuffle
- Progress bar
- Volume
- Lyrics button

SUBSCRIPTIONS:
Free:
- Ads
- Limited skips
- Standard audio quality

Premium:
- No ads
- Unlimited skips
- Ultra HD audio
- Offline downloads
- Exclusive music

ADMIN PANEL:
Admins can:
- Upload music (mp3, wav, flac)
- Add artists
- Add albums
- Create playlists
- Manage users
- See revenue
- Control ads
- Approve content

TECHNOLOGY:

BACKEND:
- Node.js
- Express
- MongoDB
- JWT Authentication
- Stripe for payments
- AWS S3 or Cloudinary for music storage

WEB APP:
- Next.js (React)
- Tailwind CSS
- Framer Motion
- Progressive Web App

MOBILE APPS:
- React Native (Android & iOS)
- Same backend
- Offline mode
- Push notifications
- Media controls on lock screen

AI SYSTEM:
- Recommend music based on listening history
- Create smart playlists
- Suggest new artists
- Detect mood from behavior

SECURITY:
- Encrypted passwords
- Token authentication
- Anti-piracy streaming
- Download protection

OUTPUT:
Generate:
- Full backend APIs
- Database schema
- Web UI
- Mobile UI
- Admin dashboard
- Demo music data
- Deployment instructions
